# BookNet 📚

BookNet, React ve TypeScript kullanılarak geliştirilmiş bir kitap keşif uygulamasıdır.

## Özellikler

- Kitap arama
- Kitap detaylarını görüntüleme
- Favorilere kitap ekleme
- Responsive tasarım
- Open Library API entegrasyonu

## Kullanılan Teknolojiler

- React
- TypeScript
- React Router
- HTML5
- CSS3
- Axios
- REST API
- Vite

## Kurulum

```bash
npm install
npm run dev
```
