# 📚 BookNet

BookNet is a modern book discovery application built with React and TypeScript. Users can search for books, explore detailed information, manage their favorite books, and receive personalized book suggestions through a clean and responsive interface.

## ✨ Features

- 🔍 Search books using the Open Library API
- 📖 View detailed book information
- ❤️ Add and remove books from favorites
- 📚 Manage a personal favorites collection
- 🎯 Book recommendation page
- 🔎 Search within favorite books
- 📱 Fully responsive design
- 🎨 Modern and user-friendly interface

## 🛠️ Technologies Used

- React
- TypeScript
- React Router DOM
- Axios
- HTML5
- CSS3
- Vite
- Open Library API
- React Toastify

## 📸 Screens

- Home Page
- Book Detail Page
- Favorites Page
- Book Recommendation Page

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/selenakinn/BookNet.git
```

Navigate to the project folder:

```bash
cd BookNet
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🌐 API

This project uses the Open Library API to retrieve book information and cover images.

API Documentation:

https://openlibrary.org/developers/api
